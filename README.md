## Markdown 转 PDF

可使用 [Resumd](https://resumd.t9t.io/) 将 Markdown 简历排版并导出为 PDF。

使用方式：

1. 打开简历 Markdown 文件并复制内容。
2. 访问 [Resumd](https://resumd.t9t.io/)。
3. 粘贴 Markdown，调整主题与排版。
4. 导出 PDF，并检查分页、字体及联系方式是否正确。
